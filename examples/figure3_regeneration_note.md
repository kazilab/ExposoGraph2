# Figure 3 Regeneration Usage Note

Figure 3 is the Module 5 multi-carcinogen interaction and synergy figure.

The accepted local source-of-truth command is:

```bash
python tools/generate_figure3.py
```

The command regenerates the notebook and CSV/PNG/PDF/SVG outputs under
`Figures_Notebook/`.

This is a usage note, not an executable short example. WP12 does not rerun the
figure-generation command because Figure 3 regeneration was completed in WP10.
